# Disclaimer

## Использование сторонних сервисов

Этот пайплайн использует public/cabinet API Wildberries и API mpstats.io. Использование этих сервисов регулируется их Terms of Service. Перед использованием:

1. **Прочитай WB Terms** (https://seller.wildberries.ru) — особенно про API usage.
2. **Прочитай MPStats Terms** (https://mpstats.io).
3. **Не обходи rate limits.** Если WB/MPStats throttle — подожди, не использовать proxy ротацию для обхода защиты.

## Что НЕ запрещается

- Получение данных по своим карточкам через Seller API (это твои данные)
- Покупка cabinet сравнений (этот endpoint предназначен селлерами для аналитики)
- Использование MPStats Analytics API в рамках вашего тарифа
- Парсинг publicly available SERP результатов через user-agent imitation

## Что МОЖЕТ быть рисковано

- **Быстрый частый запуск** (>5 раз/час) на WB SERP — может привести к временному IP throttle (но не банят аккаунт)
- **Высокая частота cabinet purchases** — выбираешь свой собственный месячный лимит
- **Использование без свежих cookies** — может выглядеть как несанкционированный access

## WB менять API без предупреждения

WB регулярно меняет:
- Формат JSON ответов (добавляет/убирает поля)
- URL endpoints (особенно cabinet)
- Структуру Excel экспортов

Если что-то перестало работать после WB update — нужно адаптировать парсеры. Этот pipeline предоставляется **as is**, без гарантии что он будет работать через месяц/год.
